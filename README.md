# ✨ Taskflow — Modern To-Do List

A sleek, modern to-do list web application built with pure **HTML**, **CSS**, and **JavaScript**. Features a stunning dark glassmorphism UI with smooth animations and full local storage persistence.

🔗 **Live Demo:** [https://shahanmusthakim.github.io/to-do-list/](https://shahanmusthakim.github.io/to-do-list/)

## 🚀 Features

| Feature | Description |
|---------|-------------|
| ➕ **Add Tasks** | Create tasks with custom category & priority |
| ✅ **Complete Tasks** | Animated checkbox with satisfying bounce effect |
| ✏️ **Edit Tasks** | Click the pencil icon to inline-edit any task |
| 🗑️ **Delete Tasks** | Smooth slide-out removal animation |
| 🔍 **Filter Tasks** | Sliding pill filter — All / Pending / Completed |
| 📊 **Progress Bar** | Gradient progress bar showing completion percentage |
| 📈 **Live Stats** | Real-time Pending & Done counters with animations |
| 💾 **Local Storage** | All tasks persist across browser sessions |
| 🔔 **Toast Notifications** | Elegant slide-up notifications for every action |
| 🧹 **Clear Completed** | Batch delete done tasks with staggered animation |
| ⌨️ **Keyboard Shortcut** | Press `/` to quickly focus the input |

## 🎨 Design Highlights

- 🌑 **Dark Glassmorphism** — Frosted glass cards with `backdrop-filter: blur`
- 🟣 **Ambient Floating Blobs** — Animated purple, pink & blue gradient orbs
- 🌈 **Gradient Accents** — Logo, buttons, progress bar, and checkboxes
- ✨ **Micro-Animations** — Smooth transitions on every user interaction
- 🔤 **Inter Font** — Clean, modern typography from Google Fonts
- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet & desktop

## 🚀 Getting Started

### Option 1: Open Directly
Simply double-click `index.html` to open in your browser.

### Option 2: Local Server
```bash
# Using Python
python -m http.server 3000

# Then open http://localhost:3000
```
